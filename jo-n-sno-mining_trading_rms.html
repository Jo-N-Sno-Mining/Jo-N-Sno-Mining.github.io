Signals

The signal layer across Pine Script, MT5, and a standalone web dashboard — same strategy, three surfaces, one webhook router.

📈

Pine Script v5 Signal Panel

TradingView indicator painting SMA crossover BUY/SELL markers (green/red) on chart + ML Optimal RSI layer (OB 70 / OS 30) with its own BUY/SELL markers.

4 alert conditions emit JSON for the webhook router: SMA BUY/SELL and RSI BUY/SELL — each includes symbol, action, price, strategy, timestamp.

🕹️

Standalone Web Dashboard

Dark TradingView-style UI: canvas candlesticks, SMA fast (blue) / slow (red) lines, BUY/SELL markers, RSI markers, watchlist sidebar, ML Optimal RSI panel.

Signal logic layer (detectSignals / calcSMA / calcRSI) is real and works on any candle array — swap the simulated data generator for a live API.

JO_SNO_SignalPanel_web.html →

⚙️

MT5 Indicator (4 arrow buffers)

4 arrow buffers: SMA BUY (green up-arrow), SMA SELL (red down-arrow), RSI BUY (blue up-arrow), RSI SELL (gold down-arrow).

SMA lines drawn as OBJ_TREND chart objects (blue fast / red slow). Alert popups fire on each crossover; push notifications enabled via MT5 settings.

Indicator paints signals — does not place trades. Companion EA reads iCustom() values or alerts feed the webhook/external executor.

JO_SNO_SignalPanel_mq5.mq5 →

🔗

Webhook Router

Signal-to-webhook execution router receives Pine alert JSON, validates it, checks whitelist / position limits / rate rules / regime filter / duplicate suppression, then decides: execute via API, queue for review, or ignore.

Deterministic rules engine first, ML regime filter later. Every decision logged to audit + state (open positions, recent actions per symbol, cooldowns).
